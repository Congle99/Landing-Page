# AuraBook Landing Page

Landing Page giới thiệu sản phẩm AuraBook được xây dựng bằng **React + Vite**, tập trung vào giao diện hiện đại, responsive và tích hợp chatbot AI hỗ trợ người dùng.

## Demo

Website: https://landing-page-git-feature-cheiron1.vercel.app/

## Công nghệ sử dụng

* React.js
* Vite
* CSS3
* Google Gemini API
* Vercel

## Tính năng

* Responsive trên Desktop, Tablet và Mobile.
* Hero Banner hiện đại.
* Hiển thị danh sách sản phẩm.
* Giao diện trực quan, thân thiện với người dùng.
* Chatbot AI tích hợp Google Gemini hỗ trợ giải đáp thông tin sản phẩm.

## Cài đặt

Clone repository:

```bash
git clone <repository-url>
```

Di chuyển vào thư mục dự án:

```bash
cd Landing-Page
```

Cài đặt thư viện:

```bash
npm install
```

Tạo file `.env` từ `.env.example`

```env
VITE_GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

Khởi động project:

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Dự án được triển khai trên Vercel.

## Lưu ý

API Key của Google Gemini **không được đưa lên GitHub**.

Để sử dụng chatbot, hãy:

1. Tạo file `.env`.
2. Thêm API Key của Google Gemini vào biến:

```env
VITE_GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

3. Chạy lại project bằng:

```bash
npm run dev
```
